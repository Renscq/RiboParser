# 8 Acknowledgements

RiboParser/RiboShiny was developed to provide an integrated platform for comprehensive analysis and visualization of ribosome profiling data.

## Software and open-source ecosystem

RiboParser depends on and interoperates with widely used open-source tools in RNA-seq and Ribo-seq analysis, including Bowtie, SAMtools, Cutadapt, STAR, BEDTools, Subread, RSEM, gffread, SRA Toolkit, UCSC utilities, and Python scientific packages including NumPy, pandas, Polars, SciPy, scikit-learn, statsmodels, pysam, matplotlib, seaborn, and Biopython.

## Related resources

The workflow is designed to interoperate with RiboCode, RiboTISH, SeRP-related analysis workflows, bedGraph and bigWig genome-browser signal tracks.

## Example datasets

The documentation uses public RNA-seq and Ribo-seq datasets to demonstrate the workflow, especially `GSE67387`.

Nedialkova DD, Leidel SA.

We thank all developers, users, and researchers who provide feedback, report issues, test RiboParser on different species and sequencing datasets, and contribute to the improvement of RiboParser and RiboShiny.
