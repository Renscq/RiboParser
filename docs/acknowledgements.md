# 8 Acknowledgements

RiboParser integrates common tools and workflows used in RNA-seq and Ribo-seq analysis.

Related tools include:

- Bowtie
- SAMtools
- Cutadapt
- STAR
- BEDTools
- Subread
- RSEM
- gffread
- SRA Toolkit
- UCSC utilities
- Python scientific packages

RiboParser and RiboShiny were developed to support comprehensive analysis and visualization of ribosome profiling data.
