# 2.3 GitHub

## Purpose

Install the development version directly from GitHub source.

## Clone and install

```bash
git clone https://github.com/Renscq/RiboParser.git
cd RiboParser

pip install build
python -m build
pip install .
```

## Editable development mode

```bash
git clone https://github.com/Renscq/RiboParser.git
cd RiboParser
pip install -e .
```
