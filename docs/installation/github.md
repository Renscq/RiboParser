# 2.3 GitHub

Install RiboParser from GitHub source:

```bash
git clone https://github.com/Renscq/RiboParser.git
cd RiboParser
pip install build
python -m build
pip install .
```

For development:

```bash
git clone https://github.com/Renscq/RiboParser.git
cd RiboParser
pip install -e .
```

Check installation:

```bash
riboparser -v
riboparser -m
```
