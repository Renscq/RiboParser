# 1.1 Overview

RiboParser provides a complete workflow for RNA-seq and ribosome profiling data analysis.

## Major functions

- reference genome and transcriptome preparation
- Bowtie indexes for genome, mRNA, rRNA, tRNA, and ncRNA
- STAR genome index and RSEM transcriptome index construction
- RNA-seq and Ribo-seq cleaning, classification, alignment, and quantification
- offset table generation
- read density generation and merging
- periodicity, metagene, coverage, and correlation analysis
- gene-level quantification and retrieval
- codon-level pausing, occupancy, decoding time, selection time, CoV, odds ratio, and meta-codon analysis
- smORF scanning, filtering, evidence evaluation, and integration
- utility functions for FASTA, FASTQ, bedGraph, Bowtie, RSEM, and merged Ribo-seq results
