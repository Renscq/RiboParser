# 5.4 Ribo-utils commands

| Command | Function |
|---|---|
| `rpf_Shuffle` | Generate shuffled control data |
| `rpf_Shift` | Analyze frame-shift-related profiles |
| `rpf_Retrieve` | Retrieve RPF or density information |
| `rpf_Bam2bw` | Convert BAM signal to bigWig-compatible files |
| `rpf_Geneplot` | Plot gene-level Ribo-seq signal |
