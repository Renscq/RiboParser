# 5.2 Remaining Ribo-utils commands

Commands already covered in workflow pages are not repeated here.

## `rpf_Shuffle`

```bash
rpf_Shuffle -h
```

```text
usage: rpf_Shuffle [-h] -r RPF -o OUTPUT [-l LIST] [-s SEED] [-i]
```

## `rpf_Bam2bw`

```bash
rpf_Bam2bw -h
```

```text
usage: rpf_Bam2bw [-h] -b BAM -o OUTPUT [-p PSITE] [-m MIN] [-M MAX] [--strand] [--normalize] [--thread THREAD]
```

## `rpf_Geneplot`

```bash
rpf_Geneplot -h
```

```text
usage: rpf_Geneplot [-h] -r RPF -g GENE -o OUTPUT [-t TRANSCRIPT] [-n] [-f {0,1,2,all}]
```
