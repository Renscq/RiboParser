# 5.3 Ribo-pausing commands

| Command | Function |
|---|---|
| `rpf_Pausing` | Relative codon pausing score |
| `rpf_Occupancy` | Codon occupancy |
| `rpf_CoV` | Coefficient of variation |
| `rpf_Cumulative_CoV` | Cumulative coefficient of variation |
| `rpf_CDT` | Codon decoding time |
| `rpf_CST` | Codon selection time |
| `rpf_Odd_Ratio` | Codon odds ratio |
| `rpf_Meta_Codon` | Meta-codon density analysis |

Detailed examples are provided in the `Workflow → Quality control` pages.
