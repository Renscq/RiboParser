# 5.3 Helper scripts

## bedGraph

| Command | Function |
|---|---|
| `bg2meta` | Convert bedGraph signal to meta-profile input |
| `rpm_smooth` | Smooth RPM signal |

## Bowtie / RSEM

| Command | Function |
|---|---|
| `merge_bwt_log` | Merge Bowtie mapping log files |
| `merge_rsem` | Merge RSEM expected_count, TPM, or FPKM columns |

## FASTA

| Command | Function |
|---|---|
| `fa_gc_sum` | Calculate GC summary |
| `fa_len_flt` | Filter FASTA by sequence length |
| `fa_len_sum` | Summarize FASTA sequence lengths |
| `fa_split` | Split FASTA files |
| `line_feed` | Normalize line breaks |
| `nt2aa` | Translate nucleotide sequences |
| `rand_seq` | Generate random sequences |
| `retrieve_seq` | Retrieve FASTA sequences by ID |
| `revs` | Reverse or reverse-complement sequences |

## FASTQ

| Command | Function |
|---|---|
| `fq_len_flt` | Filter FASTQ by read length |
| `fq_len_sum` | Summarize FASTQ read lengths |
| `fq_length` | Calculate read length distribution |
| `fq_split` | Split FASTQ files |
| `fq_trim` | Trim FASTQ reads |
| `fq2fa` | Convert FASTQ to FASTA |
| `fq2txt` | Convert FASTQ to text |
| `phred_quality` | Evaluate Phred quality |
| `simulate_fastq` | Simulate FASTQ reads |

## RiboCode / RiboTISH / Unix

| Command | Function |
|---|---|
| `ribocode_bed_format` | Format RiboCode BED output |
| `ribotish_format` | Format RiboTISH output |
| `dos2unix` | Convert Windows line endings |
