# 5.8 Helper scripts

## bedGraph

| Command | Function |
|---|---|
| `bg2meta` | bedGraph meta-profile processing |
| `rpm_smooth` | RPM signal smoothing |

## Bowtie

| Command | Function |
|---|---|
| `merge_bwt_log` | Merge Bowtie alignment logs |

## FASTA

| Command | Function |
|---|---|
| `fa_gc_sum` | GC summary |
| `fa_len_flt` | Filter FASTA by length |
| `fa_len_sum` | Summarize FASTA length |
| `fa_split` | Split FASTA |
| `line_feed` | Normalize line breaks |
| `nt2aa` | Translate nucleotide sequence |
| `rand_seq` | Generate random sequences |
| `retrieve_seq` | Retrieve sequences by ID |
| `revs` | Reverse or reverse-complement sequences |

## FASTQ

| Command | Function |
|---|---|
| `fq_len_flt` | Filter FASTQ by read length |
| `fq_len_sum` | Summarize FASTQ read length |
| `fq_length` | FASTQ read length distribution |
| `fq_split` | Split FASTQ |
| `fq_trim` | Trim FASTQ |
| `fq2fa` | Convert FASTQ to FASTA |
| `fq2txt` | Convert FASTQ to text |
| `phred_quality` | Evaluate Phred quality |
| `simulate_fastq` | Simulate FASTQ reads |
