# 5.1 Toolkit overview

RiboParser v0.2.5 exposes multiple command-line tool groups.

| Group | Scope |
|---|---|
| Ribo-quality | reference, QC, offset, density, merge, periodicity, metaplot, coverage, correlation, quantification |
| Ribo-pausing | pausing, occupancy, CoV, CDT, CST, odds ratio, meta-codon |
| Ribo-utils | shuffle, frame shift, retrieval, BAM-to-bigWig, gene plot |
| RNA | RNA density and offset |
| SeRP | SeRP overlap, peak, and property analysis |
| smORF | smORF scanning, filtering, evidence, and integration |
| Helper scripts | FASTA, FASTQ, bedGraph, Bowtie logs, RSEM outputs, RiboCode, RiboTISH, and Unix helpers |
