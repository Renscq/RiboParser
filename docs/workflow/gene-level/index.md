# 4.6 Gene-level analysis

Gene-level analysis summarizes RNA-seq or Ribo-seq signals at gene, transcript, CDS, UTR, or density-profile level.

## Submodules

| Section | Command | Purpose |
|---|---|---|
| 4.6.1 | `rpf_Quant` | gene/CDS-level quantification |
| 4.6.2 | `rpf_Coverage`, `rpf_Percent` | gene-body coverage and region-level percentage |
| 4.6.3 | `rpf_Corr` | sample-level reproducibility |
| 4.6.4 | `rpf_Retrieve` | retrieve formatted gene density |
