# 4.5.1 Check

## Purpose

`rpf_Check` evaluates BAM quality, read length distribution, filtered BAM output, read saturation, and gene saturation. It is the first RiboParser QC step after alignment.

## Input files

| Input | Description |
|---|---|
| BAM | transcriptome-aligned BAM, usually `Aligned.toTranscriptome.out.bam` |
| transcript annotation | `gene.norm.txt` generated by `rpf_Reference` |
| output prefix | sample name or group name |

## Parameters

| Parameter | Meaning |
|---|---|
| `-b / --bam` | input BAM file |
| `-t / --transcript` | normalized transcript annotation file |
| `-o / --output` | output prefix |
| `--thread` | number of threads |
| `-g` | filter reads by mapping loci; usually `1` for uniquely mapped reads or `0` for all reads |
| `-a` | aligner source of BAM tags, such as `star`, `hisat2`, or `bowtie2` |
| `-r` | count reads aligned to negative strand |
| `-l` | only retain the longest transcript per gene |
| `-s` | calculate read and gene saturation |

## Example

```bash
for bam in ../../3.star/*Aligned.toTranscriptome.out.bam
do
  prefix_name=$(basename $bam Aligned.toTranscriptome.out.bam)

  rpf_Check \
    -b $bam \
    -s \
    --thread 10 \
    -t ../../../1.reference/norm/gene.norm.txt \
    -o $prefix_name \
    &>> $prefix_name".log"
done
```

## Output files

| Output | Description |
|---|---|
| `sample.bam` | filtered and sorted BAM |
| `sample.bam.bai` | BAM index |
| `sample_length_distribution.txt` | read length distribution table |
| `sample_length_distribution.pdf/png` | read length distribution plot |
| `sample_gene_saturation.txt` | gene saturation table |
| `sample_gene_saturation.pdf/png` | gene saturation plot |
| `sample_reads_saturation.txt` | read saturation table |
| `sample_reads_saturation.pdf/png` | read saturation plot |
| `sample.log` | running log |

## Result interpretation

Ribo-seq libraries should show a dominant footprint length, typically in a narrow RPF range. Gene and read saturation curves should become stable when sequencing depth is sufficient.

|---|---|
