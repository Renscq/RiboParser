# 4.5.1 Check

Quality check evaluates read length distribution, filtered BAM output, read saturation, and gene saturation.

For Ribo-seq, strict QC should include:

- peak detection of dominant RPF length
- expected dominant RPF length range: 26–34 nt
- proportion of reads in expected range
- gene detection rate
- saturation curve behavior

When the slope of the gene count curve approaches zero, the sequencing data is usually close to saturation.

## Command help

```bash
rpf_Check -h
```

```text
usage: rpf_Check [-h] -t TRANSCRIPT -b BAM -o OUTPUT [--thread THREAD]
                 [-g {0,1}] [-a {star,hisat2,bowtie2}] [-r] [-l] [-s]

Required arguments:
  -t TRANSCRIPT    input gene annotation file
  -b BAM           input BAM file
  -o OUTPUT        output prefix

Options:
  --thread THREAD  number of threads
  -g {0,1}         filter reads by mapping loci; 0 = all reads, 1 = uniquely mapped reads
  -a ALIGNER       screen mapped loci from BAM generated by star, hisat2, or bowtie2
  -r               count reads aligned to negative strand
  -l               keep only longest transcripts
  -s               calculate RPF saturation
```

## RNA-seq quality check

```bash
cd ./3.rna-seq/5.riboparser/01.qc

for bam in ../../3.star/*Aligned.toTranscriptome.out.bam
do
  prefix_name=$(basename $bam Aligned.toTranscriptome.out.bam)

  rpf_Check \
    -b $bam \
    -s \
    --thread 10 \
    -t ../../../1.reference/norm/gene.norm.txt \
    -o $prefix_name \
    &>> $prefix_name".log"
done
```

