# 4.5.5 Merge density

## Purpose

Merge single-sample density files into one matrix-like file for downstream multi-sample analysis.

## `merge_dst_list`

### Function

Generate the sample list file required by `rpf_Merge`.

### Parameters

| Parameter | Meaning |
|---|---|
| `-l / --list` | input density files |
| `-o / --output` | output sample list file |

### RNA-seq example

```bash
merge_dst_list \
  -l ../04.density/*_rna.txt \
  -o RNA.file.list
```

### Ribo-seq example

```bash
merge_dst_list \
  -l ../04.density/*_rpf.txt \
  -o RIBO.file.list
```

### Sample list format

```text
Name                         File                                                        Type
wt_ribo_YPD1                 /path/to/SRR1944912_rpf.txt                                  Ribo
wt_ribo_YPD2                 /path/to/SRR1944913_rpf.txt                                  Ribo
```

## `rpf_Merge`

### Function

Merge all density files defined in the file list.

### Parameters

| Parameter | Meaning |
|---|---|
| `-l / --list` | density file list generated by `merge_dst_list` |
| `-o / --output` | output prefix |

### Examples

```bash
rpf_Merge \
  -l RNA.file.list \
  -o RNA \
  &>> RNA.log

rpf_Merge \
  -l RIBO.file.list \
  -o RIBO \
  &>> RIBO.log
```

## Output files

| Output | Description |
|---|---|
| `RNA.file.list` | RNA-seq sample list |
| `RNA_merged.txt` | merged RNA-seq density |
| `RIBO.file.list` | Ribo-seq sample list |
| `RIBO_merged.txt` | merged Ribo-seq density |
| `*.log` | running log |

## Interpretation

The merged file is the core input for all downstream multi-sample analysis. Check that sample names are unique and sample type labels are correct.
