# 4.5 Quality control

Quality control determines whether RNA-seq and Ribo-seq libraries are suitable for downstream analyses.

## Shared QC for RNA-seq and Ribo-seq

- read length distribution
- mapping statistics
- transcript/gene body coverage
- sample correlation
- expression or density quantification

## Ribo-seq-specific QC

- P-site offset estimation
- 3-nt periodicity
- frame-specific RPF density
- metagene profiles around TIS/TTS
- codon-level RPF distribution
- codon pausing score
- codon occupancy
- codon decoding time
- codon selection time
- meta-codon profiles
