# 4 Workflow

The RiboParser workflow is organized into:

1. Reference preparation
2. Raw data download
3. Raw data cleaning
4. Alignment and quantification
5. Quality control
6. Gene-level analysis
7. Codon-level analysis
8. smORF analysis

The original README uses public RNA-seq and Ribo-seq data to demonstrate the complete analysis process. In this documentation website, each large README section is split into a focused page.
