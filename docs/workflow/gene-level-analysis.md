# 4.6 Gene-level analysis

Gene-level analysis summarizes RNA-seq or Ribo-seq signals by genes or CDS regions.

## Main goals

- gene-level RPF quantification
- CDS-region quantification
- group-wise comparison
- sample-level merged profiles
- RiboShiny-compatible output generation

## Related commands

```bash
rpf_Quant -h
rpf_Coverage -h
rpf_Corr -h
```

## Suggested outputs

```text
*_quant.txt
*_rpm.txt
*_rpkm.txt
*_tpm.txt
*_correlation.pdf
*_coverage.pdf
```
